# Introduction

architxt is a knowledge-workbench for turning source documents into structured, explorable contextual graphs backed by a vector memory bank.

## What you can do

- **Upload documents** and extract entities, relationships, and mental models.
- **Build contextual graphs** that connect people, systems, concepts, and evidence.
- **Explore graphs visually** with the Views page: select entities, arrange the canvas, inspect mental-model detail, and export or send views to Workspace pages.
- **Reflect** on the graph with free-text questions and get synthesized answers.
- **Sync** selected documents and tags with a Hindsight memory bank.
