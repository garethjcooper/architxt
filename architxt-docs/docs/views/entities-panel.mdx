# Entities Panel

The **Entities** panel is the left column of the Views page. It lists every grounded entity in the selected bank and lets you choose which entities and edges appear on the canvas.

## What is listed

- One row per grounded entity in the bank.
- Expanding an entity reveals its edges grouped by directed endpoint pair (`source → target`).
- The group header represents all edges between the same two entities, regardless of edge type or label.
- Expanding a group shows the individual edges underneath, including the underlying grounded edge and any contextualised variants.

## Filters

| Control | Purpose |
|---|---|
| **All** | Show every entity in the bank. |
| **View** | Show only entities that are currently on the canvas. |
| **Search** | Filter entities and edges by name, id, or edge type. |

## Checkboxes

| Checkbox | Effect on the canvas |
|---|---|
| **Entity** | Include or exclude the entity. |
| **Edge group header** | Toggle every edge in the group on or off at once. |
| **Individual edge** | Toggle a single edge beneath a group. |

When only some edges in a group are selected, the group checkbox shows an indeterminate state.

When you select any edge, both of its endpoint entities are implied onto the canvas automatically.

## Edge direction

Edges are grouped and rendered using their real mental-model direction (`source → target`). The canvas arrow points from source to target. When an edge is detected as bidirectional, markers are drawn on both ends.

## Find in panel

If you use the canvas find shortcut (`F3` / find) to locate an item on the graph, that item is also revealed in the Entities panel so you can inspect and toggle it from there.

## Edge hierarchy

The top level lists entities. Under each entity, edges are grouped by their directed endpoint pair. The group row shows the endpoint pair and a count of edges in the group. Expanding the group reveals the individual edges, letting you turn on a whole relationship or select specific contextual variants.
