# Overview

The **Views** page is where you explore and compose the contextual graph visually. It is scoped to the selected Hindsight server and bank, so every view, node, and edge belongs to a specific bank.

## Layout

The page is a three-column workspace.

| Column | Purpose | Learn more |
|---|---|---|
| **Entities** | Browse grounded entities and their edges, then choose what appears on the canvas. | [Entities Panel](./entities-panel) |
| **Canvas** | View, arrange, and select nodes and edges. | [Canvas](./canvas) |
| **Detail** | Inspect the mental-model content behind selected nodes or edges. | [Detail Panel](./detail-panel) |

You can resize the columns by dragging the handles between them, and toggle each column on or off from the top bar.

## Top bar

The top bar selects the Hindsight server and bank, and toggles the left and right columns. The rest of the page’s controls live in the green panel header below it.

## View tabs

Views are opened as tabs in the panel header.

| Action | How it works |
|---|---|
| **New view** | Creates a blank view named automatically. |
| **Rename** | Edits the active view name. |
| **Delete** | Removes the active view permanently. |
| **Undo / Redo** | Steps through changes to the active view. |
| **Timeline** | Toggles the timeline panel for the active view. |

## Export

The export menu in the toolbar offers quick exports of the current canvas **view**:

- Copy or download the canvas as a PNG image.
- Copy or download the canvas as an SVG image.
- Copy or download the view as a Mermaid flowchart.

For full contextual-graph exports — including JSON, GraphML, GEXF, Cypher, CSV, C4 (Structurizr DSL), C4 (Mermaid), and ArchiMate XML — use the **Export** button on the Graph tab of the contextual graph manager. See the [Graph export documentation](../context-patches/graph#export) for details.

## Send to Workspace

The **Save to...** button sends the current view to a curated Workspace page. You can create a new page or add to an existing one. Before sending, a modal lets you choose which formats to include:

| Format | Output |
|---|---|
| **Flowchart** | A Mermaid flowchart diagram of the current view. |
| **Graph** | A canonical graph section with the view's nodes and edges. |
| **Table** | Node and edge tables derived from the canonical graph, using the same table structure as the Graph focus modal's **Add table to page** action. |

Flowchart is selected by default. At least one format must be selected. When multiple formats are selected, they are all included in the same standard envelope on the target page.

If the target page already contains a graph, architxt asks for confirmation before merging.

## Persistence

Open view tabs and active panel layout are restored per server and bank when you return to the page.

## How it fits into architxt

```text
Context Patches ──► contextual graph ──► Views
                                            │
                                            ├── canvas editing
                                            ├── mental-model detail
                                            ├── timeline snapshots
                                            └── export / send to Workspace
```

- **Context Patches** builds and maintains the graph.
- **Views** lets you inspect, arrange, and compose that graph visually.
- **Workspace** receives view content through curated pages.

## Summary

Views is the visual layer on top of the contextual graph. It gives you a bank-scoped canvas, an entity-driven selection panel, layout controls, mental-model detail, timeline snapshots, and export options, all tied back to the rest of the Workspace.
