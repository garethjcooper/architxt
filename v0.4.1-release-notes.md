# v0.4.1 Release Notes

## Highlights

This release is primarily a **documentation milestone** for the architxt v0.4.1 docs site, alongside a set of UI/server fixes that landed on the branch.

- **New docs site published at** `https://architxtlabs.com`
- Complete Docusaurus docs-first site with `routeBasePath: '/'`, no blog.
- New documentation categories:
  - **Getting Started** — installation, quick-start (with video), where to start.
  - **Core Concepts** — entities, contexts, documents, metadata, tags, mental models, bank settings, directives, AQL.
  - **Workspace** — UI overview, contextual data, reflect queries & session items, preview & curated pages, and Focus areas (narrative, diagram, table, graph, evidence).
  - **Context Patches** — overview, graph tab, candidates (experimental), mental models, sync jobs.
  - **Hindsight Sync** — overview, document, entity, directive, mental-model, and bank-settings sync pages.
- Focus pages now explain how evidence, diagrams, and tables carry from the Focus modal into curated pages.
- Sidebar polish: active-category backgrounds fixed at every nesting level, dark-mode chevrons now visible.

## UI / Server fixes

- Reflect query input race eliminated and session hook stabilized.
- Reflect result no longer snaps selection back to a new step.
- Session items ordered by `created_at` descending.
- Mermaid diagram viewer: fit-to-width toggle, type inference in Markdown, robust resize behavior.
- Sync job logs now show server name/address instead of numeric DB id.

## Technical details

- `architxt-docs/package.json` version bumped to `0.4.1`.
- `docusaurus.config.ts` configured for production domain `https://architxtlabs.com`.
- Broken-link check enabled with `onBrokenLinks: 'throw'`.
- All docs MDX files pass build and typecheck.
